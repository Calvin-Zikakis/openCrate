# Code of conduct

Be straightforward and kind. Disagree about how the app should behave as much as you like; keep it about the app.
Personal attacks, harassment and discrimination have no place here. Assume the other person is trying to make the
app better.

If someone's behaviour in an issue, pull request or discussion makes it hard for others to take part, tell the
maintainer through GitHub. Reports are read in confidence. The maintainer may edit or remove comments and, for
repeated or serious behaviour, block the account.
